# ElMeGGa OmaDesktop

Colección de plugins para la barra de **Omarchy Quattro**. Desde la barra puedes controlar la música, revisar las actualizaciones, consultar el uso del sistema y ver el pronóstico.

| Plugin | Qué hace | Repositorio |
|---|---|---|
| **ElMeGGa OmaPlayer** | Controla reproductores compatibles con MPRIS. Muestra carátula, metadatos, progreso, visualizadores de audio y letra sincronizada opcional. | [OmaPlayer](https://github.com/megga-ernesto/omaplayer) |
| **ElMeGGa OmaUpdate** | Busca actualizaciones de Omarchy, Arch, AUR, mise, Flatpak y Snap. Compara versiones, marca paquetes importantes y muestra el plan de actualización en una terminal. | [OmaUpdate](https://github.com/megga-ernesto/omaupdate) |
| **ElMeGGa OmaVitals** | Muestra métricas configurables de CPU, memoria, GPU, disco, red y otros recursos, con gráficas en vivo y una lista de procesos con búsqueda, filtros y agrupación. | [OmaVitals](https://github.com/megga-ernesto/omavitals-monitor) |
| **ElMeGGa OmaWeather** | Muestra las condiciones actuales y los pronósticos de 24 horas y cinco días de Open-Meteo, con búsqueda de ciudades y detalles meteorológicos. | [OmaWeather](https://github.com/megga-ernesto/omaweather) |

Los cuatro plugins ofrecen **Base**, **Cristal** y **Blur** en **Ajustes → Apariencia**. Base sigue el tema de Omarchy. Cristal añade una superficie translúcida con un toque del acento del tema. Blur difumina el fondo mediante Hyprland cuando el efecto está disponible.

Cada repositorio contiene el código, los requisitos, las capturas y su propio comando de instalación. Puedes instalar los widgets de forma independiente.

## Tema

[Rubí OLED](https://github.com/megga-ernesto/elmegga.rubi-oled) ofrece negro puro, acento rubí, superficies translúcidas y una galería de 15 fondos. Su identificador de instalación es `elmegga.rubi-oled`.
